Crawling dan Scraping Data

Materi ini menjelaskan proses pengumpulan URL berita dari Detik.com, ekstraksi isi artikel, dan penyusunan dataset untuk analisis lebih lanjut.

1. Crawling URL Berita

Tautan berita dikumpulkan dari kategori Sport dan Finance di Detik.com. Setiap kategori ditargetkan sebanyak 100 URL, sehingga target total crawling adalah 200 URL.

Notebook: Scraping dan crawling.ipynb · Python 3

import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin
import time

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 (KHTML, like Gecko) "
                  "Chrome/154.0.0.0 Safari/537.36"
}

def ambil_link_berita(base_url, target=100):
    links = []
    for halaman in range(1, 15):
        url = f"{base_url}/indeks?page={halaman}"
        response = requests.get(url, headers=HEADERS, timeout=15)
        response.raise_for_status()
        soup = BeautifulSoup(response.text, "html.parser")

        for a in soup.find_all("a", href=True):
            href = urljoin(base_url + "/", a["href"])
            if base_url in href and "/d-" in href and href not in links:
                links.append(href)
                if len(links) >= target:
                    break
        if len(links) >= target:
            break
        time.sleep(1)
    return links[:target]

link_sport = ambil_link_berita("https://sport.detik.com", 100)
link_finance = ambil_link_berita("https://finance.detik.com", 100)

print(f"Sport berhasil di-crawling: {len(link_sport)} berita")
print(f"Finance berhasil di-crawling: {len(link_finance)} berita")
print(f"Total URL: {len(link_sport) + len(link_finance)}")

Target crawling: 100 URL Sport dan 100 URL Finance. Jumlah aktual bergantung pada tautan yang berhasil ditemukan saat kode dijalankan.

2. Scraping Isi Berita

URL hasil crawling diproses dengan Trafilatura. Isi artikel yang berhasil diekstrak disimpan bersama label kategori, sedangkan URL yang gagal diekstrak dicatat terpisah. Proses ini menggunakan jeda acak 2–5 detik.

Notebook: scraping.ipynb · Python 3

import trafilatura
import time
import random

def ekstrak_dataset(links, label, target=100):
    data = []
    gagal = []

    for link in links:
        if len(data) >= target:
            break
        try:
            downloaded = trafilatura.fetch_url(link)
            isi = trafilatura.extract(downloaded, favor_recall=True) if downloaded else None
            if isi:
                data.append({"isi_berita": isi, "label": label})
            else:
                gagal.append(link)
        except Exception:
            gagal.append(link)

        print(f"[{label}] {len(data)}/{target}")
        time.sleep(random.uniform(2, 5))

    return data, gagal

data_sport, gagal_sport = ekstrak_dataset(link_sport, "sport", 100)
data_finance, gagal_finance = ekstrak_dataset(link_finance, "finance", 100)

print("Sport berhasil:", len(data_sport), "| gagal:", len(gagal_sport))
print("Finance berhasil:", len(data_finance), "| gagal:", len(gagal_finance))

Jumlah artikel yang berhasil dapat kurang dari target jika halaman tidak dapat diambil atau teks tidak berhasil diekstrak.

3. Pembentukan Dataset

Data Sport dan Finance digabungkan menjadi satu DataFrame, diberi kolom ID, lalu disimpan ke file CSV untuk tahap preprocessing dan klasifikasi berikutnya.

Notebook: dataset.ipynb · Python 3

import pandas as pd

data_sport = data_sport[:100]
data_finance = data_finance[:100]

df = pd.DataFrame(data_sport + data_finance)
df.insert(0, "id", range(1, len(df) + 1))

print("Ukuran dataset:", df.shape)
df.head()

df.to_csv("dataset_berita.csv", index=False, encoding="utf-8")
print("Dataset berhasil disimpan.")

Kolom dataset terdiri dari id, isi_berita, dan label. Target ukuran dataset adalah 200 baris apabila 100 berita dari masing-masing kategori berhasil diekstrak.
